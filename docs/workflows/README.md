# Workflows

Procedures for work that gets repeated. One document per activity.

A **standard** states a constraint that holds at all times and is cited by id. A **workflow** is a sequence you follow
once, start to finish, for one kind of task. Workflow steps carry no ids and are renumbered whenever the procedure
improves; the rules they cite never move.

| Workflow | Run it when | Standard it enforces |
|---|---|---|
| `docs/workflows/documentation-review.md` | reviewing an existing reference doc, Javadoc, or comment block | `docs/standards/documentation.md` |
| `docs/workflows/test-review.md` | reviewing existing tests | `docs/standards/testing.md` |

A workflow **cites** rule ids rather than restating them (**F2**). A step that reads as complete without the standard
open has probably grown a copy of a rule that nothing keeps equal.
